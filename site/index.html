Built for coding agents

Your agent gets a canvas

Scobe runs an MCP server so Cursor, Claude Code, Codex, and v0 can create frames, snapshot pages, and lay out UI while you watch. Click Connect in Scobe and it wires up your agent — locally, or through a private, token-protected tunnel for cloud agents. 

// ~/.cursor/mcp.json — written for you by Connect
{
  "mcpServers": {
    "vanta": {
      "type": "http",
      "url": "http://127.0.0.1:29980/mcp"
    }
  }
}
