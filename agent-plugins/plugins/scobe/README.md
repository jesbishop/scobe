Scobe is an infinite canvas of live browsers and editable frames. With this plugin your agent can build on the canvas while you watch: create frames with auto-layout, add text and shapes, style them, and snapshot any live web page into editable layers.

**Prerequisites**

Install [Scobe](https://github.com/jesbishop/scobe/releases/latest) and open it at least once. Scobe sets up the `scobe` command the plugin uses; keep the app open while your agent works.

**Features**

- **Read the canvas**: List frames, layers, and live browsers, with sizes and hierarchy.
- **Write to the canvas**: Create artboards and auto-layout frames, add text, rectangles, and ellipses, then move, resize, restyle, rename, duplicate, or delete them.
- **Snapshot live pages**: Pull any region of an open browser into the canvas as editable layers, not a flat screenshot.
- **Drive browsers**: Open and navigate live browsers on the canvas and take screenshots.

**Examples**

**Prompt:** "Build a landing page hero on the Scobe canvas with auto-layout".

**Expected behavior:**

- Your agent checks the canvas, creates a frame with auto-layout, and adds a headline, subtext, and buttons.
- New layers shimmer on the canvas as they appear.

**Prompt:** "Snapshot the sidebar from my open browser into editable layers in Scobe".

**Expected behavior:**

- Your agent finds the open browser, snapshots the sidebar, and places it beside the browser as editable layers you can restyle.
